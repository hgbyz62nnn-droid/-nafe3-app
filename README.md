# مدربين الإسماعيلية — NAFE3

منصة بتوصل متدربين بمدربين شخصيين معتمدين في الإسماعيلية: بروفايل وCV لكل مدرب،
اشتراك ودفع جوه التطبيق، وشات خاص فيه فلتر بيمنع مشاركة أرقام موبايل أو حسابات
سوشيال ميديا للحفاظ على خصوصية الطرفين.

## إيه اللي جاهز دلوقتي

- تسجيل حساب (متدرب / مدرب) وتسجيل دخول
- مدرب بيعمل بروفايل + CV، وبيفضل "قيد المراجعة" لحد ما الأدمن يوافق عليه
- المتدرب بيتصفح المدربين المعتمدين ويشترك في باقة
- الدفع: **وضع تجريبي دلوقتي** (لحد ما تفتح حساب Paymob) — تقدر تفعّل الاشتراك بضغطة زرار وتكمل تجربة باقي التطبيق
- شات بين المتدرب والمدرب بعد الاشتراك، مع فلتر بيمنع إرسال أرقام موبايل/حسابات تواصل
- لوحة أدمن بسيطة للموافقة أو رفض طلبات المدربين

## اللي محتاج تعمله قبل ما تشغّل

1. **تثبيت Node.js** (لو مش مثبت عندك): حمّله من https://nodejs.org (اختار نسخة LTS)
2. افتح Terminal / Command Prompt جوه فولدر المشروع

## خطوات التشغيل (على جهازك)

```bash
# 1. ادخل فولدر المشروع
cd nafe3-app

# 2. نزّل المكتبات
npm install

# 3. اعمل نسخة من ملف الإعدادات
cp .env.example .env
# (على ويندوز استخدم: copy .env.example .env)

# 4. اعمل حساب أدمن (مرة واحدة بس)
node seed-admin.js admin@nafe3.com كلمة_سر_قوية

# 5. شغّل السيرفر
npm start
```

بعدين افتح المتصفح على: **http://localhost:3000**

- سجّل دخول بحساب الأدمن اللي عملته عشان توافق على أول مدرب
- اعمل حساب "مدرب" تجرب بيه، واملأ البروفايل
- ادخل بحساب الأدمن ووافق على المدرب
- اعمل حساب "متدرب" واشترك مع المدرب وجرب الشات

## إزاي تفعّل الدفع الحقيقي (Paymob) لما تبقى جاهز

1. افتح حساب على https://paymob.com (محتاج أوراق شركتك NAFE3 للتفعيل الكامل)
2. من لوحة التحكم خد: **API Key**، **Integration ID** (بتاع الدفع بالكارت)، **Iframe ID**
3. حطهم في ملف `.env`:
   ```
   PAYMOB_API_KEY=...
   PAYMOB_INTEGRATION_ID=...
   PAYMOB_IFRAME_ID=...
   ```
4. سجّل رابط الـ webhook في لوحة Paymob: `https://your-domain.com/api/subscriptions/webhook/paymob`
5. عيد تشغيل السيرفر — من هنا وأي اشتراك جديد هيوديك على صفحة دفع Paymob الحقيقية بدل الوضع التجريبي

⚠️ **مهم:** كود التكامل مبني على الـ API الشائع بتاع Paymob وقت كتابته، لكن بوابات الدفع بتحدّث الـ API بتاعها بين فترة وفترة. قبل ما تشغّله بفلوس حقيقية، راجع https://docs.paymob.com وقارن بالخطوات في `lib/paymob.js`، وكمان لازم تضيف التحقق من توقيع (HMAC signature) بتاع الـ webhook قبل ما تعتبر أي دفع "ناجح" فعلياً — ده جزء أمان أساسي مكتوب عليه تعليق في الكود مكانه بالظبط.

## إزاي ترفعه أونلاين (بعد ما تجربه محلي وتتأكد إنه شغال زي ما عاوز)

أسهل خيارات لمبتدئين:
- **Railway** (railway.app) — بيدعم Node.js + قاعدة بيانات، وسهل جداً تربطه بمجلد المشروع
- **Render** (render.com) — نفس الفكرة، فيه باقة مجانية للتجربة

في الاتنين: بترفع الكود (عادة عن طريق GitHub)، بتحط متغيرات الـ`.env` بتاعتك في لوحة التحكم بتاعهم، وهما بيشغّلوا `npm install && npm start` تلقائي.

## هيكل المشروع

```
nafe3-app/
├── server.js              نقطة تشغيل السيرفر
├── db.js                  قاعدة البيانات (SQLite) وتعريف الجداول
├── seed-admin.js           سكريبت عمل حساب أدمن
├── lib/
│   ├── paymob.js           تكامل بوابة الدفع
│   └── privacyFilter.js    فلتر منع الأرقام/حسابات التواصل في الشات
├── middleware/auth.js       التحقق من تسجيل الدخول والصلاحيات
├── routes/
│   ├── auth.js              تسجيل / دخول / خروج
│   ├── coaches.js           بروفايلات المدربين + مراجعة الأدمن
│   ├── subscriptions.js     الاشتراكات والدفع
│   └── chat.js               الشات
└── public/                  الواجهة (HTML/CSS/JS)
```

## حاجات مهمة قبل ما تفتحه لعملاء حقيقيين

- **فلتر الخصوصية دلوقتي بسيط (regex)** — بيتحايل عليه لو حد كتب الرقم بحروف عربي أو فرانكو أو بمسافات غريبة. لو الموضوع مهم جداً ليك، محتاجين طبقة أذكى بعدين.
- **التحقق من توقيع Paymob webhook** لسه محتاج يتضاف (موضّح مكانه في `routes/subscriptions.js`)
- SQLite كويسة للبداية، بس لو الاستخدام كبر جامد ممكن تحتاج قاعدة بيانات أقوى زي PostgreSQL بعدين
